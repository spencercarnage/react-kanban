# Project structure

| Path                     | What goes there                                                                                       |
| ------------------------ | ----------------------------------------------------------------------------------------------------- |
| `app/`                   | Next.js route files only (`page.tsx`, `layout.tsx`, `globals.css`). `page.tsx` is a Server Component. |
| `components/layout/`     | Layout and styling-only wrappers that are used in more than one place (`BoardGrid`, `Modal`).         |
| `components/inputs/`     | Anything the user types into or picks from: forms, fields, buttons, selects.                          |
| `components/navigation/` | Headers and navigation.                                                                               |
| `components/display/`    | Components that present data (board, cards, characters, celebration, skeletons).                      |
| `components/utils/`      | Non-visual components: `AppProviders`, `BoardProvider`, `ErrorBoundary`.                              |
| `hooks/<domain>/`        | Reusable hooks, grouped by domain (`hooks/board`, `hooks/dnd`).                                       |
| `utils/<domain>/`        | Reusable plain functions and types, grouped by domain (`utils/board`, `utils/relay`, `utils/dnd`).    |
| `__generated__/`         | relay-compiler output. Git-ignored and regenerated by the npm scripts. Never edit by hand.            |
| `schema.graphql`         | Rick and Morty API schema. Refresh with `npm run relay:schema`.                                       |

Rules:

- Every `.tsx` file that isn't a Next.js route file lives under
  `components/`. Tests are the exception.
- One component per file. The file name matches the default-exported
  component.
- Tests sit next to the file they cover (`moveItem.ts` →
  `moveItem.test.ts`).
